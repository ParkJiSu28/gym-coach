# 근비대 코치 사용설명서

> 운동 기록 → 부위별 피로도 → 논문 기반 분석 → 다음 세션 처방까지 한 앱에서.
> **근력(1RM)보다 근육 크기(근비대)** 를 목표로 처방합니다.

---

## 1. 아이폰에 설치하기 (처음 한 번)

1. 아이폰 **Safari** 로 앱 주소(배포 후 받은 `https://….github.io/…` 주소)를 엽니다.
2. 아래쪽 **공유 버튼**(□↑)을 누릅니다.
3. **"홈 화면에 추가"** → **추가**.
4. 이제 홈 화면의 **근비대 코치** 아이콘으로 실행합니다. 주소창 없이 앱처럼 열립니다.

- 한 번 열고 나면 **인터넷이 없어도(헬스장 지하) 동작**합니다.
- 컴퓨터는 꺼 두어도 됩니다. 앱은 GitHub 서버에 있고, **운동 기록은 내 아이폰 안에만** 저장됩니다.
- 앱이 업데이트되면 다음 실행 때 자동으로 바뀝니다.

> ⚠️ 반드시 **홈 화면 아이콘으로** 쓰세요. Safari 탭으로만 쓰면 iOS 가 오래 안 쓴 사이트의 데이터를 지울 수 있습니다.

## 2. 처음 시작하기 (5~10분)

### ⓪ 캡처로 한 번에 가져오기 (추천) — `기록` 탭 → **캡처 글자로 가져오기**

다른 앱 기록 화면을 하나하나 칠 필요 없이, 캡처의 글자를 복사해서 붙여넣으면 앱이 종목·무게·횟수를 찾아줍니다.

1. 다른 앱의 운동 기록 화면을 **캡처**합니다 (한 화면에 다 안 보이면 여러 장).
2. **사진** 앱에서 캡처를 열고 글자를 **길게 눌러** 선택 → **모두 선택** → **복사**.
3. 근비대 코치 → `기록` 탭 → **캡처 글자로 가져오기** 칸을 길게 눌러 **붙여넣기** → **분석**.
4. 미리보기에서 확인합니다.
   - **운동한 날짜**를 고르세요 (캡처에 날짜가 없으면 오늘로 되어 있습니다).
   - 종목이 맞는지 확인 — 못 알아본 종목은 "종목을 선택하세요"에서 고르세요.
   - 숫자가 잘못 읽혔으면 **세트 수정**.
   - "세트 없음"은 캡처에서 잘린 종목입니다 → 다음 캡처로 가져오세요.
5. **N개 종목 저장**. 캡처가 여러 장이면 한 장씩 반복합니다.

> 광고·버튼 글자(저장, 메모, 웜업 등)는 자동으로 걸러집니다. 같은 캡처를 두 번 저장하면 기록이 중복되니 주의하세요 (중복은 아래 "직접 입력한 기록"에서 삭제).

### 💻 PC에서 입력하고 폰으로 옮기기 — `기록` 탭 → **기기 간 기록 옮기기**

지난 기록을 몰아서 입력할 땐 PC 키보드가 훨씬 빠릅니다.

1. **PC** 브라우저에서 https://parkjisu28.github.io/gym-coach/ → `기록` 탭에서 입력합니다.
   - **Enter** = 다음 세트 칸 (값이 복사되고 무게 칸으로 이동), **Ctrl+Enter** = 저장
2. 다 입력했으면 PC에서 **기기 간 기록 옮기기 → 보낼 코드 만들기 → 코드 복사**.
3. 카카오톡 **나와의 채팅**에 붙여넣어 보냅니다 (메모·메일도 가능).
4. **폰**에서 그 메시지를 길게 눌러 **복사** → 근비대 코치 `기록` 탭 → **받은 코드 붙여넣기** → **받기 (기존 기록에 합치기)**.

- 폰에 있던 기록은 **지워지지 않고 합쳐집니다.** 같은 코드를 두 번 받아도 중복되지 않습니다.
- 같은 날짜의 직접 입력 기록은 하나로 합쳐집니다.
- 함께 옮겨지는 것: 운동 기록 · 직접 만든 종목 · 컨디션 체크인. **루틴은 옮겨지지 않으니**, 받은 뒤 폰에서 `오늘` 탭 → **내 기록으로 루틴 추천**을 다시 누르세요.
- 반대로 폰 → PC 도 같은 방법입니다.

### ① 지난 기록 옮겨 적기 — `기록` 탭 → **지난 기록 직접 입력**

다른 앱에 있던 기록을 날짜별로 입력합니다.

| 칸 | 입력 방법 |
|---|---|
| 날짜 | 운동한 날 (오늘 이후는 입력 불가) |
| 운동 | 목록에서 선택 (없으면 기록 탭 → 운동 추가 → "목록에 없는 운동 만들기") |
| 세트별 무게·반복 | 1세트 칸 입력 → **세트 추가** 누르면 같은 값이 복사됨 → 다른 값만 고치기 |
| RIR | 재본 적 없으면 **"모름"** 그대로 두기 |

→ **기록 저장**. 같은 날 다른 종목도 날짜는 그대로 두고 종목만 바꿔서 계속 입력하면 됩니다.

**얼마나 넣어야 하나요?**
- 무게·횟수 처방용: 종목별로 **가장 최근 1~2회분**이면 충분합니다.
- 운동 요일·부족한 부위 추론용: **최근 4주치**를 넣을수록 정확합니다.

### ② 버튼 하나로 루틴 받기 — `오늘` 탭 → **기록 기반 추천**

1. **운동 가능 요일**을 누릅니다 (예: 월·수·금). 고르지 않으면 기록에서 자주 운동한 요일로 정합니다.
2. **내 기록으로 루틴 추천** 을 누릅니다.
3. **추천 결과**에서 확인합니다.
   - 요일별 세션(예: `월 전신 A`), 종목, **무게 × 횟수 × 세트 · RIR · 휴식 시간**
   - "왜 이렇게 추천하나요?" → 근거와 논문 링크
4. 마음에 들면 **이 루틴 적용**.

## 3. 운동하는 날

### 시작
`오늘` 탭에 **오늘: 전신 A** 처럼 오늘 할 세션이 나옵니다 → **시작**.
휴식일이면 "오늘은 휴식일"과 다음 세션이 보이고, 그래도 하고 싶으면 **그래도 오늘 운동하기**.

### 세트 기록 — `기록` 탭
각 종목 카드에:
- **목표**: 예) `증량 · 목표 82.5kg × 6회 · RIR 2`
- **지난번**: 지난 기록
- 무게·반복은 처방값이 미리 채워져 있습니다. −/+ 또는 숫자를 눌러 수정.
- **몇 개 더 할 수 있었나요? (RIR)** → 0·1·2·3·4+ 중 선택, 모르면 **모름**
- **세트 완료 ✓**

### 휴식 타이머
세트 완료를 누르면 자동으로 시작합니다.
- 남은 시간이 크게 표시되고, 끝나면 **소리**(비프 3번)가 납니다.
- **−15초 / +15초** 로 목표 조절.
- 운동 중엔 화면이 꺼지지 않게 유지합니다(지원 기기).

> 🔈 소리가 안 들리면: 아이폰 **무음 스위치**를 끄고 볼륨을 올리세요.
> 화면이 꺼진 상태에서는 iOS 제한으로 알림이 오지 않습니다 — 앱을 켜 둔 채로 쉬세요.

### 종목 바꾸기 (예: 벤치프레스 → 스미스 벤치프레스)
종목 카드 오른쪽 위 **교체** → 같은 부위 대체 종목 목록(또는 검색) → 선택 →
- **이번만**: 오늘만 바꿈
- **루틴에도 반영**: 다음부터 그 종목으로 계속

### 기록 고치기
기록된 세트 줄의 **수정** → 무게·반복·RIR 변경 → **수정 저장**. ✕ 는 삭제.

### 종료
**운동 종료** → 끝. 다음번 처방이 자동으로 바뀝니다.

## 4. 다음번 처방은 이렇게 바뀝니다

| 지난 기록 | 다음 처방 | 배지 |
|---|---|---|
| 처음 하는 종목 | 상한 횟수를 2~3개 여유 있게 할 무게 찾기 | 기준점 측정 |
| 범위 안 (예: 6~10회 중 8회) | 같은 무게, 반복 +1 | 반복 수 +1 |
| 모든 세트가 상한(10회) 달성 | 무게 올리고 하한(6회)부터 | 증량 |
| 하한 미달 (5회 이하) | 추정 1RM 기준으로 무게 낮춤 | 감량 |
| 목표보다 너무 실패에 가까움 (RIR 직접 기록 시) | 같은 무게·반복 유지 | 유지 |
| 메소사이클 마지막 주 / 피로 신호 | 세트 절반, 무게 −10%, RIR 4+ | 디로딩 |

세트 수는 **부위 회복도·컨디션·주간 볼륨**에 따라 ±1 조정됩니다.
**메소사이클**: 4주(설정 가능) 동안 목표 RIR 3 → 1(고립 0)로 점점 실패에 가깝게, 그다음 1주 디로딩.

## 5. 피로도 보기 — `회복` 탭

- 부위 15곳의 **회복도 %** 와 "80% 회복까지 약 N시간"
- **전신 부하**: 이번 주 하드 세트 ÷ 평소 주평균 (1.5 넘으면 급증)
- **디로딩 판단**: 수행 하락·컨디션 저하·볼륨 급증 신호
- **컨디션 체크인**: 수면·근육통·의욕·스트레스(1~5) → 점수가 낮으면 그날 세트를 줄입니다

> 회복도는 세트 수·실패 근접도·경과 시간으로 계산한 **추정치**입니다. 실제 근육통·컨디션과 함께 판단하세요.

## 6. 분석 — `분석` 탭

- **분석 리포트**: 부위별 `현재 주 N세트 → 논문 권장 범위 → 할 일(+N세트 / 유지 / 줄이기)` + 근거 논문 링크
  - 훈련 방식 점검: 저반복 비중, 휴식 시간, RIR 기록 여부, 한 종목만 하는 부위, 시티드 레그 컬 권장 등
- **최근 7일 부위별 볼륨** 그래프 (초록 띠 = 최적 범위)
- **추정 1RM 추이**, **정체 구간 감지**
- **운동 이력**, **백업 · 복원**

## 7. 루틴 관리 — `루틴` 탭

- **주간 일정**: `월 · 전신 A` 처럼 요일별 세션
- **운동 가능 요일 변경** → **요일 변경 적용**: 요일 수에 맞는 분할로 **내 기록 기준으로 다시 짭니다**
  - 2~3일 → 무분할(전신) · 4일 → 상·하체 · 5일 → 상·하체+밀기·당기기·하체 · 6일 → 밀기·당기기·하체 ×2
  - 전신 운동을 연속 이틀 배치하면 경고가 나옵니다
- **구성 편집**: 세트 수 ±, 종목 삭제·추가 → 변경 저장
- **메소사이클 처음부터**

---

### 메모에 적어 둔 루틴 가져와서 점검받기
`루틴` 탭 맨 아래 **"내 루틴 가져와서 점검"** 칸에 메모 글을 그대로 붙여넣고 **읽고 점검하기**를 누르세요.

```
상체A 루틴 (벤치프레스 50*8 5세트, 펙덱플라이 45*15,50*15,55*10 3세트, …) 하체 A 루틴 (…)
```

- **읽는 규칙**: "○○ 루틴"으로 루틴을 나누고, `무게*횟수`를 세트로 읽습니다. `50*8 5세트`처럼 한 값만 있으면 5세트로 채웁니다. 슈퍼세트, 쉼표 빠짐, `57.5,8` 같은 오타도 읽습니다. 최고 무게의 60% 미만 세트는 워밍업으로 보고 볼륨에서 뺍니다.
- **인식 못한 종목**은 노란 칸이 뜨면서 목록에서 직접 고를 수 있습니다.
- **점검 결과**
  - ② 부위별 주간 세트를 지금과 수정안으로 나란히 보여줍니다. 빨간색은 회복 한계(MRV) 초과, 노란색은 최소 유효량(MEV) 미만입니다.
  - ③ 수정안을 근거 논문과 함께 보여줍니다.
    - **빼기**: MRV를 넘는 부위에서 같은 날 겹치는 동작을 하나 뺍니다.
    - **세트 줄이기**: 그 부위만 쓰는 고립 운동부터 줄이고, 스쿼트·데드는 둔근 때문에 줄이지 않습니다.
    - **세트 늘리기와 추가**: MEV 미만 부위에 적용합니다.
    - **교체**: 라잉 레그컬은 시티드 레그컬로 바꿉니다 (Maeo 2021).
  - ④ 종목마다 **다음 목표 무게×횟수**를 보여줍니다. 반복 범위 상한에 모두 닿으면 증량, 범위 안이면 반복 +1, 하한 미만이면 감량입니다.
- **수정안 적용** 또는 **원래대로 적용**을 누르면 그 루틴이 내 루틴이 되고, `오늘` 탭에서 그 순서대로 처방합니다.
- 가져온 루틴은 날짜가 없어서 **운동 기록으로는 저장되지 않습니다.** 첫 운동부터 기록하면 그다음 처방이 실제 기록 기준으로 바뀝니다.

## 8. 백업 (꼭 해두세요)

기록은 **아이폰 안에만** 있습니다. 폰을 바꾸거나 앱을 지우면 사라집니다.

1. `분석` 탭 → **백업 내보내기** → **파일에 저장** → iCloud Drive 선택
2. 새 폰에서: 앱 설치 → `분석` 탭 → **백업 불러오기** → 저장한 파일 선택

> 2~4주에 한 번 백업을 권장합니다.

## 9. 앱이 따르는 근비대 원칙 (근거)

| 원칙 | 앱 처방 | 근거 |
|---|---|---|
| 부위별 주 10~20세트 | 주간 볼륨을 최적 범위로 맞춤, 간접 자극은 0.5세트 | Schoenfeld 2017, Baz-Valle 2022, Pelland 2024 |
| 부위별 주 2회 이상 | 요일 수에 맞는 분할 | Schoenfeld 2016 |
| 6~30회 유효, 6~12회 효율적 | 바벨 복합 6~10 · 머신/덤벨 복합 8~12 · 고립 10~15 · 소근육 12~20 | Schoenfeld 2017·2021 |
| 실패 0~3회 전 | 메소사이클 동안 RIR 3 → 1 | Refalo 2023, Robinson 2024 |
| 반복 → 무게 순 과부하 | 더블 프로그레션 | Plotkin 2022, Helms 2016 |
| 휴식 충분히 | 복합 2.5분 · 고립 1.5분 | Schoenfeld 2016, Singer 2024 |
| 늘어난 위치 운동 | 시티드 레그 컬 등 우선 | Maeo 2021, Pedrosa 2022 |
| 적당한 종목 변화 | 교체 기능, 단일 종목 경고 | Kassiano 2022 |
| 4~8주마다 디로딩 | 메소사이클 끝 1주 | Bell 2023 |
| RIR 추정은 연습하면 정확해짐 | RIR "모름" 허용, 기록 권장 | Halperin 2022 |

## 10. 자주 묻는 질문

**Q. RIR 이 뭔지 모르겠어요.**
세트를 끝내고 "같은 자세로 몇 개 더 할 수 있었나?"입니다. 0 = 더 못 함, 2 = 두 개 더 가능. 모르면 "모름"을 누르세요. 앱이 2로 가정하고 "RIR 추정"으로 표시합니다. 기록할수록 정확해집니다.

**Q. 처방 무게가 너무 무겁거나 가벼워요.**
그냥 실제로 든 무게·횟수를 기록하세요. 다음 처방이 그 기록을 기준으로 다시 계산됩니다.

**Q. 컴퓨터랑 아이폰 기록이 달라요.**
기록은 기기마다 따로 저장됩니다. 한 기기(아이폰)에서만 쓰거나, 백업 파일로 옮기세요.

**Q. 의학적 조언인가요?**
아닙니다. 관절 통증·날카로운 통증·부상이 의심되면 중단하고 전문가와 상담하세요.

## 부록. 배포 방법 (처음 한 번, 컴퓨터에서)

1. [github.com](https://github.com) 가입 → **New repository** → 이름 예: `gym-coach`, **Public** → Create.
